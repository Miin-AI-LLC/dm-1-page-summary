Model Terms
Cairn Grove

Privacy Policy

Cairn Grove is designed around local wellness reflection: your Apple Health summaries, prompts, conversation context, and model responses stay on your device.

Effective date: July 9, 2026

Local Health Data

Cairn Grove reads only the Apple Health data types selected by the user and never writes to or modifies Apple Health data. HealthKit samples, local health summaries, prompts, conversation context, and model responses stay on the user's device. Cairn Grove does not send those data to a server.

Local Model

Cairn Grove downloads the local Gemma model only after the user approves the download. The model is stored in the app's protected storage and can be deleted from the Privacy tab. Deleting the model does not delete data stored in Apple Health.

Network Use

The only network request Cairn Grove makes is the approved model asset download. That request necessarily sends the network information needed to retrieve the file, such as IP address and HTTP request headers, to the configured model host. Cairn Grove does not include HealthKit data, prompts, summaries, conversation context, or model responses in that request.

No Accounts or Tracking

Cairn Grove does not provide user accounts, cloud inference, advertising, analytics SDKs, remote configuration, or remote crash logging.

User Controls

Users control Apple Health access in Apple Health and in Cairn Grove's Health Data Access settings. Users can change selected data types, revoke Apple Health access, and delete the downloaded model.
